# Detectors

The smoke alarm piece: salvaged smoke alarms, reassembled to look stock, chirping like their
batteries are dying. A single ESP32 drives all the horns through TB6612FNG H-bridge boards.

This folder is a PlatformIO project (classic ESP32, `esp32dev`, Arduino framework). Run
PlatformIO commands from here.

## Status

Scaffold only. There is no firmware yet.
